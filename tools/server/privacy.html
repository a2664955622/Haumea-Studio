Haumea Studio: what it sends, and what is kept

Haumea Studio can send two kinds of information to its developer: a small daily usage ping, and reports when it crashes or hits an error. Both can be turned off in the editor's preferences. Nothing else is collected. Crash diagnostics may be shared with the developer's maintainers in a private Discord channel so they can investigate without dashboard access.

The daily ping

At most once a day, Haumea Studio sends:

  • a random install ID (32 hexadecimal characters, made on your computer; it says nothing about you or your computer),
  • the version (for example 1.0.0.57) and channel (production or beta, or dev/pr for test builds),
  • the operating system: Linux, Windows or macOS.

This counts how many installs are in use, on which versions and systems. It is kept until 12 months after the install last sent a ping.

Crash and error reports

When Haumea Studio crashes or hits an error, a report can be sent with:

  • the version, commit, channel, operating system and its version, the processor type, and the graphics card and driver names;
  • where it happened in Haumea Studio's code (the stack, as offsets in its own files), and the error message if there was one;
  • the last lines of the editor's log, and which mode and window were in use.

Before a report leaves your computer, your home folder, user name, game folder and workspace are replaced by placeholders, and no map names or map contents are included. A report carries the install ID only if the daily ping is on too. Reports are kept for 6 months.

What is never kept

The server does not store IP addresses or keep access logs. It counts requests per address in memory only, for a minute, to stop floods.

Who sees it

The developer can view reports on a password-protected page. Crash alerts also go to the developer's private Discord channel with a self-contained HTML snapshot of the dashboard details, including the latest report's stack, system, graphics card and log lines. The attachment excludes install IDs and can be read by channel members without dashboard access, so the channel is kept private.
